# Bikash Ghimire Portfolio

Personal portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Development

Requirements: Node.js 20+ and pnpm 10.

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm lint
pnpm test:run
pnpm build
```

Portfolio content is maintained in `src/data/portfolio.ts`. The contact form uses Formspree and analytics are loaded through Plausible in production.
